월별 원본 데이터 업로드 · 누적관리

ZMMR0340 · ZCOE0101 · MES데이터 · ZPPR0070 4개 원본 파일을 매월 올리면 2023-01~2026-08 시계열 뒤에 이어붙습니다. 서버로 전송되지 않으며 이 브라우저의 localStorage에만 저장되는 클라이언트 전용 데모입니다 — 다른 PC·브라우저에서는 보이지 않고, 캐시를 지우면 사라집니다.

창원 전용(선택) — 광주 1세대 극판 납 사용량(kg): 로스율 분모에 가산합니다

누적 현황

계산 방식(요약) 광주·창원 '원재료 로스분석' 엑셀의 '로스분석' 시트 산식을 그대로 옮겼습니다. 납 자재(순연·경연·칼슘연·기타 45종)별로 로스 수량(kg) × 해당 월 평균 단가(출고금액합계 ÷ 출고수량합계)를 구합니다. 재고보정·슬러그·코드대체는 ZMMR0340의 이동유형으로 분류하고(상대연 출고 중 SLB 연분은 자재전표텍스트로 폐연호·초기연분 재분류, SBZ10005 광명단은 폐연호), 비-MAZ 자재는 환산표로 원재료 수량에 환산합니다. 폐극판(SLI…)·폐전지(PCC·PCM…)는 MES 불량수량 × ZPPR0070 BOM 구성부품수량 ÷ 1000으로 환산합니다. 로스율 = 납 로스 수량(kg) ÷ 납 총 투입량(kg)이며 코드대체(재분류)는 제외합니다. 창원은 엑셀처럼 '광주 1세대 극판' 납 사용량을 분모에 더할 수 있습니다(선택 입력). 광주 8월·창원 8월 워크북과 대조해 자재 × 로스유형 1,170칸이 일치함을 확인했지만, 실사용 전 현업 검증은 필요합니다(박상열_PRD.md §10 정확한 산식 미확정).

로스율 질의응답 챗봇

기간 비교·추이·이상치 등을 MOCK_SERIES(누적 데이터) 기준으로 즉시 계산합니다. 아래에서 본인 API 키를 등록하면 자유 문장을 LLM이 해석하고(숫자 계산은 항상 이 화면의 JS 엔진이 직접 수행), 키가 없으면 정해진 질문 패턴만 인식하는 규칙 기반 모드로 동작합니다.

LLM 연결 설정

API 키는 이 브라우저의 localStorage에만 저장되며 어디로도 전송되지 않습니다(질문 해석을 위해 선택한 공급사 API로만 전송됩니다). 이 파일을 다른 사람과 공유하거나 개발자 도구를 여는 사람에게는 키가 노출될 수 있으니, 공용 PC에서는 사용 후 "키 삭제"를 눌러주세요.
